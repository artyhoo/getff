## §0 The convention being codified

**Convention:** «README "What you get today" must match the install code.» Until now it lived
only in operator agent memory (`feedback_consumer_install_facts_from_code_not_readme.md`, not
reachable from the container — the facts you need are restated here). Incident 2026-09-27: an
agent answered «what does getff install?» from README + `setup.d/companions.manifest` and got it
wrong — README item 1 says «A skill (`.claude/skills/getff/`)» while the installer ships a tier
list of skills; README says 11 agents while the installer ships 12; and the `eslint@^9` pin in
`CORE_DEVDEPS` carries no written reason, so its only recorded reason went stale unnoticed.
