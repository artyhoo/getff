**Hard rules (each has historically failed the gate):**

1. **Heading depth = H3 (`###`), NOT H2.** CI regex matches `^### §1\.7 ...` — H2 silently fails.
2. **Word «applied» is required** in each heading.
3. **≥40 non-whitespace chars in EACH section body** (awk-counted, post-strip).
4. **≥1 file:line citation per section** matching `[^[:space:]]+\.[a-z]+:[0-9]+`.
5. **Mechanical-maintenance escape hatch:** `### §1.7 Skipped: <rationale ≥60 chars>` for purely structural PRs (snapshot regen, typo) with no discipline surface.

**Pre-flight grep — Worker MUST run BEFORE `gh pr create` (compose `$PR_BODY` first):**

```bash
echo "$PR_BODY" | grep -cE '^### §1\.7 (Forward|Backward)-check applied'  # must be 2
echo "$PR_BODY" | awk '/^### §1\.7 Forward-check applied/{c=1;next} /^###/{c=0} c' | tr -d '[:space:]' | wc -c  # ≥40
echo "$PR_BODY" | awk '/^### §1\.7 Backward-check applied/{c=1;next} /^###/{c=0} c' | tr -d '[:space:]' | wc -c  # ≥40
echo "$PR_BODY" | grep -cE '[^[:space:]]+\.[a-z]+:[0-9]+'  # ≥2
```
