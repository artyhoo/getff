# live-generation — kickoff

> **Goal of this umbrella:** WORKING live rule-generation in ALL THREE render stacks — **js/ts · rust · python** — as THREE THIN per-stack adapters over ONE shared generation core, NOT three parallel lanes. A consumer's interactive AI session researches its stack's real practices from LIVE docs into the neutral `ConventionNode` IR, renders through the already-ADOPTED backend for that stack, and ends up with a genuinely-researched **executable rule + a firing test that fires RED** — delivered through the pure-bash seam python-delivery-v0 ships. Serves [README.md#why-this-exists](../../../README.md#why-this-exists): «generated executable rules don't go stale» — realized across three stacks, not one.
> **What already exists (verified 2026-07-11):** the shared core is three-quarters built. Plane 1 — neutral IR (`ir/types.ts:32`, frozen) + 4 pure render backends (`backends/{astgrep,ruff,cargo,npm}`, #199/#212/#215). Plane 2 — stack-agnostic research/trust core (`research/research-port.ts:13` injectable `ResearchClient`; `research/allowlist-resolver.ts:133` `EcosystemAdapter` seam, npm+cargo shipped; only `research/allowlist.ts:21-27` Tier-0 hosts are JS-specific *data*). Plane 3 (the gap) — NO `live-research → ConventionNode` bridge: js shortcuts research→`GenerateSelection`→`generate.ts` (ESLint-direct, **SHIPPED #805/#852**), `to-node.ts` bridges only the synthesizer's OWN input→ConventionNode→npm. **CORRECTION (binding):** the js/ts live adapter Phase 1 is ALREADY MERGED to staging (#805 + #852) — the js stage is CONFIRM-AND-FRAME, not «implement Phase 1»; both the brief and prior notes calling it unstarted are stale (verified: `git log origin/staging` + `synthesizer/file-clients.ts` present).
> **Falsifiers (surface, do not assume):** (1) if the frozen IR cannot express researched rules at a workable rate (OWNER-FORK-1, decided by the LG-S1 census) that is an owner call, not a license to unfreeze silently; (2) ~~OWNER-FORK-2 (converge the js ESLint-direct generate-half onto the neutral ConventionNode bridge)~~ — **RESOLVED in #1006 (LG-S2): leave-as-is now, converge LATER via add-alongside + differential-test vs the #805 oracle; js/ts does NOT route through the shared ConventionNode bridge**; (3) «autogeneration works for rust» is CI-limited by design (`backends/cargo/firing.test.ts:37-38` `cargoPresent && !isCI`): local live-fire RED + CI render/drift only — if the owner wants CI live-fire for rust, that needs a pinned-toolchain runner, an owner call.
