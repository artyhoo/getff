## §4b §1.7 PR-body authoring mandate (paths-triggered, applies to ALL Workers below — self-evaluate)

Every stage of this umbrella touches at least one gated path (`agents/**`, `.claude/skills/**`, `.claude/rules/**`, `packages/core/**`, hooks). Workers MUST include in the **PR body** (not just commit message):

```markdown
### §1.7 Forward-check applied

<≥40 non-whitespace chars enumerating which existing disciplines were checked — with file:line evidence>

### §1.7 Backward-check applied

<≥40 non-whitespace chars enumerating the sibling-surface sweep (hook copies, prose-quote sites, both SKILL.md twins) — with file:line evidence>
```

**Hard rules (each has historically failed the CI gate):**

1. Heading depth = H3 (`###`), NOT H2. The gate regex matches `^### §1\.7 ...`.
2. Word «applied» is required.
3. ≥40 non-whitespace chars in EACH section body.
4. ≥1 `file.ext:line` citation per section.
5. Mechanical-maintenance escape: `### §1.7 Skipped: <rationale ≥60 chars>` only for purely-structural PRs (none of S1–S5 qualify — every stage has a discipline surface).

**T21 discipline (this umbrella's active trap):** the Backward-check ENUMERATES sibling surfaces (the three hook copies, the two SKILL.md prose-quote sites, both plugin/CC twins), it does NOT restate the stage diff. Delegate the sweep to `agents/backward-sweep-auditor.md` — hand it ONLY the change class, never the diff.

**Pre-flight grep (Worker runs BEFORE `gh pr create`):**

```bash
echo "$PR_BODY" | grep -cE '^### §1\.7 (Forward|Backward)-check applied'  # must be 2
echo "$PR_BODY" | grep -cE '[^[:space:]]+\.[a-z]+:[0-9]+'                  # must be ≥2
```
