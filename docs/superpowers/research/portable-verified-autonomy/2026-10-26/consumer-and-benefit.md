## C4 — total effort and cost ledger

For each baseline and trial, record identical start/end boundary, task class/complexity, candidate/requirement, host/version, account eligibility, owner and authorized destination. Baseline is today's supported workflow on comparable tasks, with source/installed fixes retained; do not handicap it with known obsolete setup.

| Measure | Count or unit / collection rule |
| --- | --- |
| Manual relays | Every human copy/forward/“worker finished”/findings return; selected accepted cycle target0. |
| Continue prompts | Each human instruction needed to restart routine work, excluding a real new product choice. |
| Decision requests | Classify necessary product/authority conflict separately from avoidable routine approvals; show evidence/options and repeated asks. |
| Active supervision | Human active minutes reading/checking/routing/recovering; quiet wall time separately. |
| Setup/migration | Unamortized human+agent time, installations/trust/auth, training, data migration and rollback preparation. |
| Recovery/maintenance | Incidents, reauth, updates, driver breakage, backup/restore, stale rules/context repair; include unsuccessful attempts. |
| Blocked time | Elapsed unavailable/decision/quota time with named owner and cause; distinguish host stopped from working. |
| Result quality | Accepted/reopened/wrong/stale candidates, meaningful finding resolution, lost ownership/duplicate effects; a rejected candidate is not a successful outcome. |
| Incremental spend | Execution, coordination, extraction, embedding/rerank, hosting/storage, optional voice/computer; currency/operation/eligible subscription/quota or UNKNOWN. |

Report raw setup S separately from recurring operator effort B_baseline and B_trial; benefit over N comparable uses is `N*(B_baseline-B_trial)-S`, plus ongoing maintenance/recovery difference explicitly. D6 has not supplied N; therefore no amortized/net improvement claim is supported. Agent tokens/model labels are not billed cost; API prices cannot price included subscription turns.

PA8 plausible route uses eligible existing CLI subscriptions, local runtime/free components and repository-backed continuity; actual extraction/embedding/provider eligibility remains unknown in M5. OpenMausBot optional remote computer/voice or native Grok new subscription cannot be smuggled into default cost. Native local scheduling consumes machine availability and subscription quota. Stop/hold on insufficient quota rather than auto top-up/new spend. No paid LLM CI introduced.
