## H2 — decisive source counterchecks

The reusable OpenMausBot unit is its **unmodified application with native accountable-owner delegation**, not extraction of its scheduler. At current pin, `server/runtime/runtime.ts:77–120` implements startup reconciliation; :525–549 handles cancellation/stopped requesters. `docs/verification/external-runtime.md:25–33` explicitly specifies external root/child `reply: poll` and status/wait polling. Those paths are not interchangeable. `server/runtime-coordinator.ts:497` returns `kind: completed`; `server/index.ts:8787–8791` supplies shared prompt sources. Exact files are preserved under evidence/openmausbot--*. This is source confirmation, not live restart or context-isolation acceptance.

Existing-session attachment is separate: OpenMausBot stores/resumes its own native Claude/Codex cursors; that does not prove safe attachment to an arbitrary already-open Codex desktop or Claude session. Native Codex messaging can address existing chats subject to user authorization, but it does not attach a Claude runtime. AIF owns tasks/sessions it starts; arbitrary-session adoption has distinct admission. D5 therefore remains a product fork.

AIF is not obsolete: current upstream README:9–11 documents automatic finding→rework and explicit manual-review handoff on nonconvergence; :269–272 says attempt-recovery defaults off, with opt-in retry debt/quarantine. Existing getff scope/acceptance wraps those capabilities. No deployed feature flag was read. Alternative “just use AIF auto mode” fails the outer-owner/consumer PA evidence threshold until demonstrated.

Current official [scheduled tasks](https://learn.chatgpt.com/docs/automations?surface=app) describe local project scheduling and require an awake computer/app for local work (snapshot lines29–31,69–75). [Pricing](https://learn.chatgpt.com/docs/pricing) separates API cost from subscription usage (snapshot lines5–16). Current [Grok Bot overview](https://docs.x.ai/grok-bot/overview) documents persistent cloud computer, collaboration and shared account computer; [plan contract](https://docs.x.ai/x-subscription/grok-bot) documents eligibility/shared weekly usage. These documents establish plausible native routes, not account or consumer access.
