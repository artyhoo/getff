## Preserved workflow and ownership

The intended cycle is agreed intent/arch → pipeline admission and actual predecessor gates → scoped executor/AIF inner cycle → applicable independent code/product/PR review → correction and recheck → authorized delivery → next eligible stage. Advisory decisions, semantic acceptance and merge authority remain distinct. AIF completion or a native host turn is not stage completion.

Existing boundaries to investigate include OpenMaus native owner, standalone local worker, AIF task/claim, runtime bridge observer, managed Dot PR owner, product reviewer, advisor mailbox, memory reader/writer, consumer installer, home intake and Windows/WSL power lifecycle. This list does not prescribe a permanent bot roster or require retaining every boundary. It identifies responsibilities whose unique behavior must survive simplification.

## Evidence and maturity vocabulary

Use evidence labels per claim, never one global maturity score:

- `DOC`: identified first-party documentation at an exact version/date.
- `SOURCE`: traced implementation at a pinned revision and line/function anchor.
- `TEST`: an actually executed bounded test with command, inputs and raw output.
- `RUNTIME`: directly observed selected installed behavior with version/environment.
- `E2E`: the complete specified cycle and relevant negative cases exercised.
- `REPORTED`: task-scoped operator/assistant report, labeled by author.
- `UNKNOWN`: needed evidence missing or contradictory; give decision impact.

Separately label `planned`, `implemented`, `installed`, `exercised`, `accepted`. A SOURCE claim does not become RUNTIME because tests exist. A passing test with fake providers cannot establish subscription eligibility. E2E is limited to its actual fixture and environment, not universal reliability.

Matrix dispositions are `SUPPORTED_ROUTE`, `PARTIAL`, `INCOMPATIBLE`, `UNKNOWN`, `NOT_RESEARCHED`. A supported route still names remaining acceptance work. An isolated probe reports `PASSED`, `FAILED`, `NOT_RUN`, `BLOCKED` or `SPECIFIED_ONLY`; these are not product acceptance verdicts.
