## §1 How to read

A **principle** is a general statement that holds on any stack. It belongs to the base core. The
concrete rule a project gets for its stack (an ESLint rule, a ruff rule, a dependency-cruiser
`forbidden` entry) is generated by research. getff's own test of a principle stays in the internal
core even when the principle ships: a consumer project gets its own generated check.

**Ships today** — measured on the react-spa greenfield fingerprint
(`tests/install-sh/baselines/react-spa/greenfield.fingerprint`, 188 files after the staging merge
`21fbbacde1f`; the pre-push checks now ship as one bundle, `packages/core/hooks/pre-push.bundle.mjs`):

- `check` — ships with something that fails or injects at run time;
- `partial` — ships, but with a named gap (opt-in, one stack only, or incomplete);
- `prose` — ships as text only (a skill, an agent, a reference, a template), nothing checks it;
- `no` — does not reach a consumer project.

New rows take the next free number in their group, so earlier numbers stay stable. A merged row keeps its number,
points at the row that absorbed it, and is marked `merged`; it is not counted.
