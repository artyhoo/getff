The source-owned procedure/check candidates were enumerated from all `.agents` Markdown and shell references, plus the portable seal/wiring population. The living-docs role already declares source-project absence and graceful degradation; no new invented implementation or success claim was introduced.

## §1.7 Self-review

**Forward-check:** canonical sources preserve the README goal and original native metadata/arguments; no sealed settings or harness model contents changed. Source-change controls exercise direct reuse, and helpers remain inside the delivered canonical population. Rule trigger additions cover both write origins.

**Backward-check:** the inventory covers contributor skills, consumer variants, distinct plugin workflows, roles, rules, bootstrap, event hooks, native adapter helpers, shared checks, generated plugin sources and deliberately retained neutral runtime/build/enforcement boundaries. The map names generated roots and platform limitations without claiming discovery equals execution. Relative-reference depth changes use explicit loaders rather than a second body.

The two plugin-only skill payloads are expanded generated derivations of canonical procedures, because an installed plugin does not carry the framework source tree. Their full-body drift remains gated.
