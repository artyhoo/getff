# getff

> getff turns a team's coding conventions into checks that fail, so an AI agent cannot quietly break them. It installs with one command into seven stacks; each stack carries its own maturity label, from beta to experimental, and the Introduction lists them.

getff is for developers who let AI agents write code in a real codebase. It wires linters, git hooks, and CI so that a broken convention stops the commit or the build. No language model runs inside any check: every gate is a plain command with an exit code, and it costs nothing to run. Every page below also exists as plain Markdown at the same address plus `.md`. Each Markdown page names the framework commit it was checked against, so you can cite a file at a fixed commit and tell when a page has gone stale.

## Proof

- The framework's own `AGENTS.md`: its generated regions end each rule with an `Enforced:` line that names which backends enforce it, and a test fails if that line is edited by hand.
- `make self-audit`: the framework runs its own hooks and its own principle tests on itself.
- The claims ledger of this site: every public claim, with the file that backs it.
